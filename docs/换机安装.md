# 带到另一台电脑

> 2026-08-20。适用：自己的另一台 Mac（出差、换机）。

## 先说清一件事：拷 .app 没用

`/Applications/Utter.app` 不是自包含的——它引用 `~/.venvs/utter` 里的
Python 环境和 `~/.cache/huggingface/` 里的模型。单拷这个图标过去，双击就是
打不开。原因写在 `packaging/build_app.py` 开头：把 MLX 的 GPU 库冻结进
app 是一个独立工程，而且分发给别人还需要付费的 Apple 开发者账号做公证。

**正确做法是：把仓库带过去，在那台机器上跑一条命令。**

## 步骤

**1. 把仓库弄到新机器上**（二选一）

```bash
git clone https://github.com/dylan-zhang-wl/utter.git
```

或者 AirDrop / U 盘拷整个 `utter` 文件夹（14M；`target/`、`node_modules/`、
`dist/` 有的话不用带）。放哪里都行。

**2. 在仓库目录里跑安装脚本**

```bash
bash packaging/setup_new_mac.sh
```

它会装好 uv、Python 环境（装在 `~/.venvs/utter`，不进 iCloud）、下载两个
语音模型（约 1.7G，**这一步要好网络——出门前在家跑**）、建签名证书、打包
到 /Applications、设开机自启。每一步做过就跳过，中断了重跑就行。

**3. 三件必须人来做的事**（脚本结束时也会提醒）

| 事 | 怎么做 | 不做的后果 |
|---|---|---|
| API key | `~/.venvs/utter/bin/utter key openai` | 转录照常，但没有翻译、润色、纪要 |
| 系统权限 | 系统设置 → 隐私与安全性：辅助功能、输入监控、麦克风、（听记线上会议还要）屏幕与系统录音 | 按住 Option 没反应也不报错 |
| 验证 | `~/.venvs/utter/bin/utter doctor`，再试一句听写 | — |

key 只存在钥匙串里（铁律 4），不跟文件夹走，新机器上要重新输一次。

## 那台机器需要什么

- **Apple Silicon Mac**：和开发机同一条路，体验一致。
- **Intel Mac**：能用。装依赖时自动换成 CPU 方案（faster-whisper），
  转录明显变慢，其他一切相同。
- **macOS 14.4 以下**：听记的「系统音频」不可用（Core Audio Taps 是 14.4
  才有的），麦克风听记和听写不受影响。
- **Windows**：还没有做。

## 装好之后，哪些要网

| 不要网 | 要网 |
|---|---|
| 听写、转录、听记出英文、灰色预览 | 翻译、润色、会后纪要（走 OpenAI） |

模型下载完之后，转录全程本地。会场没网也能记全场英文原文，回头有网再补译。
